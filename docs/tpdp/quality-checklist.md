# Checklist de calidad TPDP (PR)

- [ ] Cambios documentados en `docs/tpdp` si aplica.
- [ ] Pruebas actualizadas/añadidas y pasan en local.
- [ ] CI (`tpdp-ci.yml`) pasa en GitHub.
- [ ] No se introducen dependencias innecesarias.
- [ ] Estructura de archivos sigue las convenciones TPDP.
- [ ] Endpoints y componentes cubiertos mínimamente por tests.

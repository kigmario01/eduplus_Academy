# Herramientas y dependencias (TPDP)

## Backend (Node/Express)
- Jest: pruebas unitarias e integración.
- Supertest: pruebas HTTP sobre la app Express exportada.

## Frontend (Vite/React)
- Vitest: framework de pruebas.
- @testing-library/react: tests de componentes basados en comportamiento.

## CI
- GitHub Actions: flujo `tpdp-ci.yml` que instala dependencias y ejecuta pruebas.

## Estilo
- EditorConfig: alineación básica de formato (indentación, finales de línea).
